1　目的↑ 目錄

1.1　本文件規定 plan-tw-site-facility-layout（以下簡稱本 Skill）之安裝、操作、輸入輸出規格與限制，供各平台使用者依同一程序產製土建工地施工總平面配置圖、構造詳圖與佈置審查意見。

1.2　本 Skill 將施工總平面佈置所涉之法規控制值集中管理，並以程式繪製依比例之圖面，使配置圖之每一控制值均可追溯至法規條號與核對狀態。

2　適用範圍↑ 目錄

2.1　適用於台灣地區建築、道路、管線、橋梁等營建工程施工期間之臨時設施配置規劃、審查與出圖。

2.2　涵蓋設施：施工圍籬、大門、洗車台及沉砂池、工程告示牌、場內道路、工務所、男女廁所浴室、休息室、材料堆置場、加工場、起重機、施工構台、出土坡道、開挖周邊安全設施、施工架與安全網、護欄與護蓋、臨時用電、截水導水設施等 34 類要素。

2.3　不適用於：結構計算、擋土支撐設計、臨時用電負載計算、消防設計及交通維持計畫之審查核定。

6　安裝程序↑ 目錄

6.1　Claude

  1. 於 claude.ai 開啟「設定」之 Skills 功能，上傳 plan_tw_site_facility_layout_claude.zip；程式執行與檔案建立功能須為開啟狀態。
  2. Claude Code 使用者：將 zip 解壓縮之 plan-tw-site-facility-layout/ 置於 ~/.claude/skills/。
  3. 選用：於執行環境設定 GEMINI_API_KEY 或 OPENAI_API_KEY，以啟用 AI 示意圖。

6.2　Gemini

  1. 以個人 Google 帳號登入 gemini.google.com（電腦版網頁）。
  2. 側欄「設定」→「Skills」→「上傳」，選取 plan-tw-site-facility-layout.zip，檢查名稱與說明後「建立」。
  3. 於 Skills 清單畫面確認已建立；不得僅以對話中之「已建立」回覆為準。
  4. 若 references 子資料夾未讀入，改為扁平命名（例：references_regulations.md）並同步修改 SKILL.md 參考檔索引。
  5. 修改參考檔時，以「Replace skill」重新上傳整包。

6.3　ChatGPT

  1. 建立 Project 或 GPT，將 instructions.md 全文貼入指示欄。
  2. 解壓縮 plan_tw_site_facility_layout_chatgpt.zip，上傳知識檔 5 個：knowledge_site_layout.md、sitelayout.py、rules.json、example_site.json、details_standard.pdf。
  3. 開啟 Code Interpreter 與圖像生成功能。
  4. Code Interpreter 缺中文字型時，上傳 Noto Sans TC 字型檔並要求註冊後重新執行。

7　操作程序↑ 目錄

7.1　作業步驟

  1. 判斷需求：控制值查詢、要素原則查詢、階段漏項核對可直接回答；配置規劃、審查與出圖進入步驟 2。
  2. 建立輸入：將使用者已提供之資料寫入 site.json（第 8 章）。
  3. 缺漏檢查：執行 check；缺漏時輸出 questions.md 並停止。
  4. 詢問：一次列出全部缺漏，同主題合併為一題；可附佈置原則供選擇，但位置、尺寸、數量由使用者決定。
  5. 執行：資料齊全後執行 layout、detail 或 details。
  6. 呈現：Claude 自動以 Canvas 互動圖呈現；另交付 PNG、PDF、DXF 與審查意見。
  7. 複核：使用者以附錄 A 核對【待核】規則值。

7.2　缺漏資料詢問機制

7.2.1　使用者提示語未明確提供之項目、尺寸、數量，不得以預設值、示意值或自行配置代替。程式於 layout、detail、details 執行前自動檢查，缺漏時以結束碼 3 停止。

7.2.2　使用者明確同意以示意值繪製時，方得加 --allow-demo；圖面附註標「示意」，回覆中亦須說明。

7.5　程式 3D 鳥瞰圖

7.5.1　birdview 依 site.json 之座標繪製 3D 場景：基地、臨接道路、圍籬（大門處斷開）、場內道路、開挖範圍與周邊護欄、構造物（樓層線）、施工架防塵網、各設施、起重機（塔身、吊臂、作業半徑）、架空電線。

7.5.2　平面位置與尺寸取自 site.json；構造物高度、圍籬高度、施工架高度取自輸入值，其餘設施高度為顯示用示意值，可以 facilities[].height_m 指定。執行前同樣進行缺漏檢查。

7.6　AI 示意圖

7.6.1　提示詞採五段式：整體佈局、配色與插畫風格、插畫內容描述、要渲染進圖片的實際文字內容、絕對禁止事項。

7.6.2　AI 示意圖無比例且中文易錯字，僅供簡報與說明會；交付時須註明「示意圖，尺寸與規定以程式圖為準」。
